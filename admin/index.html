Tarmeem Site Editor

Edit the website's text and photos and publish them to GitHub. You'll need a GitHub fine-grained personal access token with Contents: Read and write access to the site repository.

How do I create a token?
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens.
  2. Repository access: Only select repositories → choose the site repository.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy the token and paste it here. Treat it like a password.
